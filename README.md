# IPL Analytics Web App

A complete IPL data analytics platform built using Python and Streamlit.
This application provides team-wise, player-wise, and season-wise IPL insights
using real match and ball-by-ball data.

## Features

- Team performance analysis
- Team vs Team head-to-head comparison
- Batting records with season filter
- Bowling records with season filter
- Player vs Player comparison
- Interactive charts and tables
- Downloadable CSV reports
- Dark theme UI

## Tech Stack

- Python
- Pandas
- NumPy
- Streamlit
- Matplotlib

- ## How It Works

- `ipl.py` handles team and head-to-head analysis
- `analytics.py` handles batting, bowling, and season-based statistics
- `streamlit_app.py` renders interactive dashboards
- Data is processed directly in Streamlit (no external API dependency)

## Deployment

This app is deployed using Streamlit Cloud.
